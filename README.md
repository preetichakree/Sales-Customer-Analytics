# Sales & Customer Analytics

## Project Overview
This project analyzes retail sales data to identify sales trends, customer purchasing patterns, product performance and regional revenue.

The project demonstrates practical skills in SQL, Python, Pandas and Power BI.

## Tools & Technologies
- MySQL
- Python
- Pandas
- Matplotlib
- Power BI
- GitHub

## Project Objectives
- Analyze overall sales and revenue.
- Identify top-performing products and categories.
- Understand customer purchasing behaviour.
- Analyze monthly sales trends.
- Compare regional performance.
- Identify repeat customers.

## Project Structure
- data/ – Sales dataset
- sql/ – Database creation and SQL queries
- python/ – Data cleaning and analysis
- powerbi/ – Dashboard development guide
- outputs/ – Analysis results and charts

## Dataset
This project uses a synthetic retail sales dataset created for learning and portfolio demonstration.
